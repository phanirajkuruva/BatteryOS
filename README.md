# BatteryOS

BatteryOS is a Digital Battery Passport platform for managing EV battery information, health reports, certificates, and verification.

## Technology Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend
- Python
- FastAPI

### Database
- PostgreSQL
- SQLAlchemy
- Alembic

### Testing
- Pytest
- Playwright
